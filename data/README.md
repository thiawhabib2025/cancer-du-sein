# Donnees

Seule la structure du dossier est versionnee ici. Les images du dataset sont dans src/data/raw/.

## Dataset

- Nom : BUSI (Breast Ultrasound Images Dataset)
- Reference : Al-Dhabyani et al., 2020, Data in Brief
- Emplacement : src/data/raw/Dataset_BUSI_with_GT/ (sous-dossiers benign, malignant, normal)

## Fichiers

- manifest.csv : index des echantillons, regenerable avec le script du projet.
- cache/ : features et fichiers intermediaires, non versionnes.
